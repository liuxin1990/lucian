# lucian

## 浪尖酷跑（冲浪跑酷原型）

基于"天天酷跑"改造的冲浪版跑酷，核心差异点是"浪是活的"：浪面动态起伏，玩家需要读浪预判。

纯 Canvas + 原生 JavaScript，无需构建工具：**直接用浏览器打开 `index.html` 即可游玩**。

- `index.html`：页面与画布
- `game.js`：全部游戏逻辑（浪面生成 / 玩家控制 / 障碍物 / 碰撞 / UI 渲染 / 主循环）

### 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 跳跃（浪峰起跳有高度加成） | 空格 / ↑ / W | 上滑（或轻点） |
| 压板潜水（钻浪管、躲水母） | ↓ / S（可按住） | 下滑 |
| 切换浪道（← 远景 / → 近景） | ← → / A D | 左右滑 |
| 空中转体花式 | 空中按 ← → | 空中左右滑 |
| 召唤大浪 | E / Q | 点按右下角按钮 |
| 暂停 | P / Esc | — |

### 玩法要点

- **三种浪型**：平浪（安全）、卷浪（压板钻入浪管持续加分，视野受限）、碎浪（白色浪花必须跳过，碰到持续扣平衡）。
- **浪况预报**：右上角显示接下来 3 波浪的类型与到达时间，提前规划。
- **平衡条**：跳跃、钻浪管、转体会消耗平衡，平稳滑行缓慢恢复；归零进入 3 秒"游泳模式"（速度减半、无法吃道具）。
- **障碍**：礁石（跳过）、水母（下滑躲避，碰到扣平衡）、鲨鱼（红色"!"预警 + 背鳍逼近，换道或跳跃躲避）。撞礁石/鲨鱼游戏结束。
- **道具**：贝壳加分；"召唤大浪"让下一波浪变高，在浪峰起跳可吃到高空金贝壳路线。
- **计分**：基础滑行分 + 浪管加成 + 出管奖励 + 转体分（转完落地加分，没转完落地扣平衡）。
